# Hitmonchanning store intro

3D product intro for [hitmonchanning.com](https://www.hitmonchanning.com): the signature merch flies in,
the Signature Deck Box opens, and the store appears out of the light.

- `hmc_intro.glb` — models + choreography, built in Blender
- `hmc-intro.js` — Three.js player, loaded by the store's Big Cartel Body code

Served via jsDelivr: `https://cdn.jsdelivr.net/gh/git-pas/hitmonchanning-store-intro@<tag>/`
